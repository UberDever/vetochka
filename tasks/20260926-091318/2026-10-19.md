## User model

- Direction (user): preserve consistency between syntax and runtime because programs inspect language syntax through reflection.
- Model (user): base syntax consists only of nyads and applications. Extended syntax provides ergonomics and lowers to base syntax.
- Model (user): everything beyond nyads and applications is an optimization from the syntactic standpoint.
- Model (user): without special runtime forms, evaluation is triage. Literals, intrinsics/opcodes, and lambdas have tagged language representations, generally `[tag, meta, ...]`.
- Model (user): the machine interprets these forms in head position. Opcodes provide host interaction and opportunities for optimization.
- Model (user): literals abbreviate corresponding nyad structures and permit optimized storage. Piths generate observable structure on Rule 3.
- Model (user): syntax lowers to base syntax. Base syntax corresponds one to one to language reduction. Runtime implements that reduction through an abstraction that permits optimization.
