## Bootstrap let ruled (final shape, OCaml-flavored)
- One form only ($rec dead): `let[clauses] do ... end`, loose block terminates; `in:` unnecessary (and `in: do...end` would not parse — label payloads are tight).
- Clause kinds by infix operator: `=` plain bind, `<~` recursive (routed through $form/fix), extensible (`:=`, `<-`, ...). Clauses lower to `[{:infix}, op, id, expr]` list entries — shape grammar-checked.
- Scoping: sequential — each RHS sees outer + preceding clauses; later clauses shadow (OCaml `let x = x + 1` idiom works). A list-shaped clause is a knot: members' RHSs see only pre-knot scope (plain, = OCaml `and`, swap idiom works) or additionally the knot's names when `<~` (= `let rec ... and ...`, mutual recursion via function-list-through-one-rec).
- `rec`/`and` stay unreserved; knots are structural, no adjacency merging. `_ = expr` for effect clauses (`_` ordinary identifier). Blocks nested in clauses need parens: `f <~ ($fn: [n] do ... end)`. OCaml's `let f x y = body` sugar deliberately not imported (vmeta taste, $fn covers).
